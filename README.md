# NLP Spell Checker — Central Bank Corpus

A domain-aware spell checker built on a Central Bank speeches corpus. It detects two distinct classes of spelling errors and surfaces ranked correction suggestions through an interactive Streamlit UI.

---

## How It Works

The system is split into two layers:

### 1. `spell_engine.py` — The NLP Engine

Trains on `central_bank_corpus.txt` at startup and builds two statistical models:

- **Unigram Model** — word frequency counts used to rank correction candidates by `P(word) = count(word) / total_words`.
- **Bigram Model** — consecutive word-pair counts used to assess contextual plausibility via Laplace-smoothed conditional probability `P(w2 | w1)`.

The engine detects three error types per word:

| Error Type | Description |
|---|---|
| **Non-Word Error** | The word does not exist in the corpus vocabulary *or* standard English. Candidates within edit distance 1 or 2 (Damerau-Levenshtein) are ranked by unigram probability. |
| **Out-of-Domain (OOV)** | The word is valid English (found in NLTK's word list) but absent from the financial corpus — flagged as domain-irrelevant (e.g., *kangaroo*, *spaghetti*). |
| **Real-Word Error (Context)** | The word exists in the corpus but a contextually better neighbour exists. Detection uses a tiered bigram probability threshold — the threshold tightens as the original phrase becomes more common, preventing over-flagging of legitimate rare phrases. |

Edit distance candidates are generated by applying all single-character **deletes, transposes, replacements, and insertions**. Distance-2 candidates are generated by composing two rounds of distance-1 edits, pre-filtered to known vocabulary to keep memory usage manageable.

### 2. `app.py` — The Streamlit Front-End

A two-panel web UI:

- **Left panel** — text editor (500-character limit) with *Check Spelling* and *Clear Text* buttons. After checking, the document is re-rendered with errors highlighted:
  - Red — Non-Word / typo
  - Orange — Real-Word context error
  - Blue — Out-of-Domain word
- **Right panel** — expandable suggestion cards for each flagged word. Clicking a suggestion applies the correction in-place and re-runs the check automatically. Below the suggestions, a searchable **Corpus Dictionary** exposes the full unigram and bigram tables.

The engine is loaded once via `@st.cache_resource` so the corpus is only parsed on first launch.

## Setup & Running

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Download the NLTK word list (one-time)
python -c "import nltk; nltk.download('words')"

# 3. Launch the app
streamlit run app.py
```

The engine will train on `central_bank_corpus.txt` automatically on first load. Subsequent loads are served from Streamlit's resource cache.

To test the engine directly from the command line (bypasses the UI):

```bash
python spell_engine.py
```

The file [Sample texts.txt](Sample%20texts.txt) contains three ready-made paragraphs with embedded errors covering all three error types — useful for a quick end-to-end demo.

Example errors embedded in the samples:

- `liqudity` → *liquidity* (Non-Word)
- `inflaton` → *inflation* (Non-Word)
- `interest rare` → *interest rate* (Real-Word / Context)
- `kangaroo`, `spaghetti` → Out-of-Domain (OOV)
